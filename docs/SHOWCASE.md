## LinkedIn "Projects" entry
**Swiftdrop: Food Delivery with Live Tracking (Android)**
Delivery app with restaurants, cart and checkout, and real-time order tracking over WebSockets. Pure-Kotlin core (A* routing, ETA, pricing, order state reducer, reconnect backoff) with 22 unit tests; custom Canvas map; OkHttp WebSocket client with an offline simulator behind one interface; Node.js tracking server with an end-to-end test. Tech: Kotlin, Jetpack Compose, Coroutines/Flow, Hilt, OkHttp, kotlinx.serialization, Node.js, GitHub Actions.
